## plugins

plugins simply put work by fork messaging, or ipc. index communicates with the webview by `process.send`ing data and node patching it through to webview.

webview does the same in reverse. sends out data using `window.api.send('plugin:to-backend', data)`, node patches it through to the forked child process.

> [!IMPORTANT] 
> "how do i make plugins?"
>
> plugins consist of two files (one is always voluntary) and one folder: index.js, webview.js and node_modules. index.js runs in the node environment, while webview.js runs on the webpage.
>
> node_modules infact isn't necessary and it is **recommended** to use something like vercel/ncc for index.js: `npx @vercel/ncc build plugins/your-plugin/index.js -e electron -o dist`
>
> (soundcloud-rpc was made this way! to check how it works, open it and scroll to the bottom. literally. you'll know where my code starts compared to the 9500ish lines of code generated by ncc.)

## features

first and most important feature, plugins. there's quite literally no limit to what you can make except for your imagination (and hardware)!!

second, although smaller, the macos-like titlebar. i am proud of it, even if it isn't completely functionally accurate.

second, customization. now this isn't something like betterdiscord or vencord where they have styles, but you have the small happy stuff. 

like accent colors or controllable window transparency. you can change the title too. or disable plugins you use but don't wanna use at the moment.

and last, the FACT THAT IT'S FULLY OPEN SOURCE and works JUST LIKE IT SHOULD in your browser!!! only with extra stuff!!

## problems

one problem you'll definitely hit is that you cannot maximize. why? electron's transparency paramter. i disabled it for your own sake. maximizing would break round corners, and get the window size stuck if you drag it away from the top.

second problem, security settings do not seem to load. this is basically because of cors. not that much i can do, considering i spent a few good hours trying to solve this. hey it's probably safer to change those in your browser either way.

third, some tracks or anything fails to load. no idea why that happens, but it's also why i added a reload button at the right top, between the arrow navigation buttons.

and also last problem but a teeny tiny one, it's simply just that the waveform accent color affects the tiny pfps too. this is because the waveform and pfps have the same class for some reason, will be patching next update
